# Legacy yescrypt mode 67000

Mode 67000 is restored for compatibility with command lines and job files made
before upstream hashcat renumbered yescrypt to mode 36100. Both mode numbers are
available and process the same `$y$` yescrypt hashes.

```powershell
M:\github\shooter_hashcat\hashcat.exe -m 67000 yescrypt.hash wordlist.txt
```

The beta module, OpenCL kernel, and test definition were forward-ported rather
than copied as independent implementations. Mode 67000 shares the maintained
mode 36100 source, including its current module API, local-memory placement,
and vectorized S-box loads. This prevents fixes and performance work from
diverging between the legacy and current mode numbers.

Mode 36100 remains available and is the preferred number for new job files.
